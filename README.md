# F2-diploma-project

Подієво-орієнтована платформа агрегації та аналізу вакансій з модулем нормалізації даних, дедуплікації та сповіщень.

- [Thesis Proposal](docs/proposal.md)

## Структура
- `docs/` — документація (Docs-as-Code)
- `src/backend/` — серверна частина (Java 21, Spring Boot)
- `src/frontend/` — клієнтська частина (React)
